# 운행일지 PWA

## GitHub Pages 배포
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 ZIP 파일의 압축을 풉니다.
3. 저장소 최상위(root)에 `index.html`, `app.js`, `style.css`, `manifest.webmanifest`, `sw.js`, 아이콘 PNG 2개를 업로드합니다.
4. 저장소의 Settings → Pages에서 배포 소스를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/(root)`로 선택하고 저장합니다.
5. 배포가 완료되면 제공된 HTTPS 주소를 iPhone Safari에서 엽니다.
6. 공유 버튼 → 홈 화면에 추가를 선택합니다.

## 기능
- 하나의 큰 상태 버튼: 빨강(시작 전) → 주황(대기 중) → 초록(운행 중)
- 대기/주행 시간 누적
- 주행 중 GPS 거리 측정 시도
- 평균연비, 유가, 공회전 연료소모량 기반 예상 유류비
- 운행기록을 브라우저 내부 저장소에 저장
- 완료된 운행기록 CSV 내보내기

## 유의사항
- GPS는 HTTPS에서만 동작합니다. GitHub Pages는 HTTPS를 지원합니다.
- iOS Safari/PWA는 백그라운드 및 화면 잠금 중 위치 추적을 제한할 수 있습니다. 실제 거리 기록을 위해서는 운행 중 앱을 화면에 띄워두는 것이 가장 안전합니다.
- 웹앱 데이터는 해당 iPhone의 Safari 사이트 데이터에 저장됩니다. 사이트 데이터 삭제, 브라우저 데이터 정리, 기기 변경 시 기록이 사라질 수 있으므로 CSV 백업을 권장합니다.
- GPS 오차, 터널, 도심 고층 건물 등에 따라 주행거리는 실제 계기판과 다를 수 있습니다.
- 유류비는 입력한 평균연비/유가/공회전 소모량을 이용한 추정치입니다.


## v3 자동 GPS 모드
- 시작 전 수동/자동 GPS 선택. 자동에서는 GPS 위치 업데이트로 정차/이동을 추정하고, 이동 중에만 거리를 합산합니다.
- 고정된 GPS 측정 주기를 강제할 수 없습니다. 정확도 25m 이내 신호를 우선 사용하고 2회 이동 / 3회 정차 판정으로 흔들림을 완화합니다.
- GPS 신호 단절, 화면 잠금, 앱 백그라운드에서는 정확한 기록을 보장할 수 없습니다. 공회전은 엔진 상태가 아닌 GPS 정차 추정입니다.
- GitHub 기존 저장소에 동일한 파일명 8개를 덮어써서 업로드한 후 Pages가 재배포되면 적용됩니다. 브라우저 캐시 갱신이 필요할 수 있습니다.
